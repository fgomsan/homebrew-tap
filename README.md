# fgomsan/tap

Official Homebrew Tap for macOS open-source tools by [Fernando Gómez Sancha](https://github.com/fgomsan).

## Install MultiScreenDock

```bash
brew tap fgomsan/tap
brew install --cask multiscreendock
```

- **Website:** [multiscreendock.fgomsan.here.now](https://multiscreendock.fgomsan.here.now/)
- **Source & Releases:** [fgomsan/MultiScreenDock](https://github.com/fgomsan/MultiScreenDock) (Apple Developer ID signed & notarized)
